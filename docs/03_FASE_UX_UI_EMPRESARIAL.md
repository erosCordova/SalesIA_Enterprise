# SalesIA Enterprise
## FASE 03 - UX/UI empresarial

**Estado:** CERRADA  
**Entregable:** Diseño UX/UI y sistema visual

## 1. Objetivo visual
Interfaz empresarial orientada a claridad, legibilidad, navegación rápida, jerarquía visual, consistencia y presentación profesional.

## 2. Sistema visual
Paleta principal: azul corporativo, cyan, blanco y grises. Se prioriza un tema claro y buen contraste.

## 3. Layout
La aplicación utiliza `MainLayout`, `Sidebar`, `Topbar` y un área principal de contenido.

## 4. Componentes reutilizables
Componentes identificados:
- `ConfirmDialog`
- `DataTable`
- `Modal`
- `ModulePage`
- `ModuleState`
- `Pagination`
- `StatCard`
- `TableToolbar`

## 5. Navegación
Áreas contempladas: Dashboard, Gestión comercial, Productos, Categorías, Ventas, Inventario, Analytics, Probabilidad, Insights, Reportes, Auditoría y Administración.

## 6. Estados de interfaz
Se contemplan estados `loading`, `empty`, `error` y `success`.

## 7. Dashboard y Analytics
El diseño contempla KPIs, tarjetas, indicadores, gráficos e insights. La implementación analítica avanzada corresponde a fases posteriores.

## 8. Formularios y tablas
Se priorizan etiquetas claras, campos agrupados, validaciones, mensajes de error y acciones identificables.

## 9. Responsive
El sistema está planteado para escritorio y tablet.

## 10. Evidencia técnica
La auditoría ejecutó `npm run build` y el frontend compiló correctamente. Vite generó la versión de producción. La advertencia de tamaño de bundle no bloquea el build.

## 11. Criterios de aceptación
Se dispone de sidebar, topbar, layout, dashboard, componentes reutilizables, sistema visual corporativo, jerarquía visual, estados de interfaz y estructura responsive.
